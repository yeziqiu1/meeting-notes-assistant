# 会议纪要助手

一款可直接在浏览器中使用的会议纪要工具，支持：

- 会议记录总结与主题分类
- 按内容数量排序并拆分类别，同一人物、项目或研究主题会合并成连贯段落
- 本地保存中心，可保存、打开、导出和删除多份纪要
- 基于原始纪要的原文问答
- 忠实润色与正式纪要整理
- TXT、Markdown、DOCX 文件导入
- 本地浏览器存储与 Markdown 导出

## 使用方式

1. 打开网页。
2. 粘贴会议记录，或导入 TXT、Markdown、DOCX 文件。
3. 使用“总结分类”“原文问答”或“润色补全”。

无需配置即可使用本地基础模式。若在设置中填写兼容 Chat Completions 的模型接口，可获得更高质量的整理、问答和润色结果。

## 隐私说明

- 会议纪要默认只保存在当前浏览器中。
- API 密钥仅保存在当前浏览器；未勾选“记住密钥”时只保留在当前页面会话。
- 配置模型接口后，点击功能按钮会将当前纪要和问题发送到你自己填写的接口地址。
